# Hotel Booking Cancellation Analysis

## Project Overview
This project analyzes hotel booking data to predict cancellations and provide dynamic pricing recommendations.

## Key Findings
- Overall cancellation rate: **37%**
- Best model: **Random Forest (88.95% ROC-AUC)**
- Top cancellation driver: **Lead Time (28.1%)**
